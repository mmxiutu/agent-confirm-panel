# agent-confirm-panel

在旁边的手机上处理 Cursor Agent 的人工确认。手机不在身边时，这些操作仍由 Cursor 自己完成。

它做三件事：

1. **批准或拒绝**终端命令和 MCP 调用。
2. **回答选择题**。指令不清楚，或方案有多处可调时，在手机上点选项，也可以自己写一句。
3. **标明来源**。每条待办都显示它来自哪个项目、哪一个 Agent 聊天框。

仓库里有两个程序：`windows/` 是电脑上的 Python 服务、Cursor 钩子和提问用的 MCP；`app/` 是 uni-app x 客户端，同一套工程可以编译到安卓、iOS 和鸿蒙。

## 原理

电脑上的服务监听 `8765`。手机用 WebSocket 连上之后，待办才会推到手机。同一时间只有一个待办，后到的请求会得到忙碌，不会叠在同一屏上。

**终端命令和 MCP 调用。** Cursor 执行前运行用户目录里的钩子 `windows/cursor_hook.py`。钩子只看本机服务：

| 状态 | 结果 |
| --- | --- |
| 没有启动服务，或手机还没连上 | 钩子返回 `ask`。Cursor 按自己的规则执行，或弹出 Cursor 自己的确认框。 |
| 服务已启动，并且手机已连接 | 命令显示在手机上。同意后继续，拒绝、终止或超时后取消。 |

读文件、搜索、改文件不经过这个钩子。大约 170 秒没有操作，按拒绝处理。

**选择题。** Cursor 自带的 AskQuestion 不会触发钩子，手机收不到桌面上那个选项框。需要用户做选择时，Agent 调用 MCP 工具 `agent-confirm-panel` / `ask`。服务名和工具名必须与此一致，钩子才会直接放行，手机只回答这一次。

**来源。** 钩子在会话开始时记下聊天和子任务。标题优先取这条聊天记录里的第一条用户消息，并截短。还没有记录时，显示会话 id 的前 8 位。子任务显示为 `子任务 …`，后台 Agent 显示为 `后台 …`。对不上聊天时，标题是 `未识别的聊天`。

## 怎么用

第一次在这台电脑上使用时，用 Cursor 打开本仓库，让 Agent 读取 `.cursor/rules/setup-new-machine.mdc`，把钩子、提问 MCP 和用户规则写进这台电脑的用户目录。这一步完成之前，服务窗口可以打开，但 Cursor 还不会把命令和选择题发到手机。同一台电脑上的其他项目不用再配。换一台电脑时，重新做这一次。

配置完成后：

1. 在电脑上启动服务，并让这个窗口一直开着。

```bat
py -3.13 -m pip install -r windows\requirements.txt
py -3.13 windows\server.py
```

也可以双击 `windows\start.bat`。它使用本机的 Python 3.13。

2. 看服务窗口打印的局域网 IP。手机和电脑在同一个局域网。手机设置页填其中一个 IP 和端口 `8765`。

3. 手机设置键变成 **[已连接]** 后就可以用。服务窗口同时会出现 `client connected`。连接成功后 App 保持屏幕常亮，断开后释放。

待处理时，状态标题下面有一行来源，例如 `agent-confirm-panel · 补上选项和来源`。点「详情」可以看到完整会话 id、命令、路径和风险。

授权（橙色）底栏是：同意、拒绝、详情、终止、设置。

选择题（深琥珀色）底栏是：提交、拒绝、详情、终止、设置。每道题是大块选项；标了「可多选」的可以点多个。每题下面都有「自定义」。每道题至少要点一个选项，或写一句自定义，才能提交。自定义可以单独提交，也可以和已选选项一起提交。

Agent 调用 `ask` 时，一次最多 6 道题，每题最多 8 个选项。每题都要有 `id`、`prompt` 和 `options`（每项有 `id`、`label`）。可多选时设置 `allow_multiple: true`。手机上的自定义输入不用在参数里再声明。`ask` 会等到手机提交、拒绝、终止或超时：

| 结果 | Agent 应该怎么做 |
| --- | --- |
| `action` 为 `choose` | 按 `answers` 里的 `option_ids`、`labels` 和 `custom` 继续。`custom` 不是空字符串时，以用户写下的文字为准。 |
| `reason` 为 `panel_offline` | 面板没连上。改用 AskQuestion，在桌面提问。 |
| `reason` 为 `panel_busy` | 面板正处理另一个聊天。稍后重试一次 `ask`。仍然忙碌就改用 AskQuestion。 |
| `action` 为 `reject` | 用户拒绝回答。不要重复同一问题。 |
| `action` 为 `stop_task` | 用户要求终止。停止当前任务。 |
| `action` 为 `timeout` | 用户没有及时回答。不要继续执行有风险的操作。 |

## 注意事项

- 第一次使用要先用 Cursor 打开本项目，让它按 `.cursor/rules/setup-new-machine.mdc` 配置自己。钩子和 MCP 写在用户目录里，不在 `windows\start.bat` 里。只双击 bat 只会启动服务，确认还到不了手机。
- 关掉服务窗口，手机就会断开。
- 手机上填局域网 IP。`127.0.0.1` 指的是手机自己。电脑有多块网卡时，窗口会打印多个地址；手机显示未连接就换另一个。Windows 防火墙要对专用网络放行 TCP 8765。
- 启动 `windows\server.py` 本身不会要求手机批准，否则服务停着时无法把它重新开起来。
- Auto-review 下，Cursor 认为安全的命令即使收到 `ask` 也可能直接执行。这和没装钩子时一样。
- SourceTree 和系统自带的命令行不经过这个钩子，用它们提交 Git 不受影响。
- 语音按钮只占位，还不能识别指令。
- 手机上需要手动允许网络与震动、关闭该 App 的电池优化、关闭自动锁屏。
- 当前真机是红米 Note 11T Pro。iOS 和鸿蒙还没有跑过。
